# Roadmap

> Plantilla inicial. Planificación temporal de features y prioridades de TaskLab.

## Propósito de esta carpeta

Mantener una vista actualizada de qué se está construyendo, qué viene después y con qué prioridad, alineado con la visión y la propuesta de valor.

## MVP inicial (referencia)

Un agente de IA conectado a un canal de comunicación que detecta posibles incidencias o peticiones, pide contexto si falta información, genera una tarea estructurada y la envía a una herramienta de gestión externa o a un panel simple de revisión.

## Próximas features planificadas

- Notificaciones de estado — DM de Discord cuando la tarea cambia a "in progress" o "done".
- (Ver también `CLAUDE.md` para features en desarrollo activo y detalle técnico)
