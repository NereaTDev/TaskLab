# La incertidumbre como problema

Descubrimiento

La comprensión no puede observarse directamente.

Lo que sí puede evaluarse es la información disponible y la incertidumbre que dicha información genera.

Proceso observado en un desarrollador

1. Localizar el código.
2. Comprender el funcionamiento actual.
3. Comprender qué debe modificarse.
4. Resolver dudas.
5. Comprender el comportamiento esperado.
6. Comenzar la implementación.

Observación

El desarrollo no comienza cuando existe mucha información.

Comienza cuando dejan de existir preguntas relevantes para el desarrollador.
