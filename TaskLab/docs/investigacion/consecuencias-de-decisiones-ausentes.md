# Consecuencias observadas

Cuando una decisión necesaria no existe aparecen cuatro consecuencias principales.

## Bloqueo

El trabajo no puede continuar.

## Trabajo atrapado

La implementación está terminada pero no puede desplegarse o validarse.

## Implementación incorrecta

Se desarrolla correctamente una solución equivocada.

## Abandono

La necesidad nunca llega a ejecutarse.
