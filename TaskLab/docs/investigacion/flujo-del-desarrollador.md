# Flujo mental del desarrollador

A partir de conversaciones con desarrolladores se observa el siguiente proceso:

1. Clasificar la tarea.
2. Estimar aproximadamente el esfuerzo.
3. Localizar la funcionalidad dentro del proyecto.
4. Preparar el entorno local.
5. Comprender el funcionamiento actual.
6. Comprender qué cambio se solicita.
7. Implementar.
8. Validar.

Observaciones:

Comprender el negocio no suele ser el primer paso.

Primero es necesario localizar la funcionalidad y entender el comportamiento existente.
