# Errores de decisión

Se identifican dos grandes familias de errores.

## Error de implementación

La decisión era correcta.

La ejecución fue incorrecta.

Ejemplos:

- bugs
- errores de programación
- errores de cálculo
- condiciones incorrectas

## Error de decisión

La implementación puede ser técnicamente correcta.

Pero la decisión original era incorrecta, incompleta o nunca llegó a hacerse explícita.

Ejemplos:

- requisito mal entendido
- comportamiento esperado ambiguo
- cambio aprobado por la persona equivocada
- falta de validación funcional

Observación

Las herramientas actuales ayudan especialmente con errores de implementación.

TaskLab pretende reducir errores de decisión.
