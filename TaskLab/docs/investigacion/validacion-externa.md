# Validación externa

Conclusiones obtenidas

## Hallazgo 1

La pérdida de contexto aparece de forma repetida en comunidades de desarrolladores.

Los equipos describen problemas relacionados con:

- tickets incompletos
- requisitos ambiguos
- decisiones perdidas
- necesidad de reconstruir el contexto

## Hallazgo 2

Muchos desarrolladores utilizan:

- git blame
- historial de commits
- conversaciones en Slack o Teams

como mecanismo para reconstruir información que no existe en la tarea.

## Hallazgo 3

El tiempo previo a escribir código suele dedicarse a comprender la funcionalidad existente.

La implementación normalmente comienza después de esa fase de comprensión.
