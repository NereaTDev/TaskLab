# Sprint 05

Estado

Completado

Objetivo

Comprender el proceso mental que sigue un desarrollador desde que recibe una tarea hasta que decide comenzar a programar.

Resultados

- Se descubrió que el razonamiento comienza localizando el contexto estructural y no interpretando directamente la petición.
- Se diferenciaron dos tipos de contexto: estructural y funcional.
- Se identificó que el proceso previo al desarrollo consiste en reducir incertidumbre mediante una secuencia de preguntas.
- Se descubrió la importancia de identificar a los propietarios del conocimiento y de la validación.
- Se definió la primera versión del Motor de Comprensión de TaskLab.

Diseñar la arquitectura funcional del MVP.
