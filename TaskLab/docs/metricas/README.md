# Métricas

> Plantilla inicial. Espacio para definir y trackear métricas clave del negocio y del producto.

## Propósito de esta carpeta

Definir qué se mide, por qué, y cómo se interpreta, para evaluar si TaskLab está cumpliendo su hipótesis de valor.

## Métricas candidatas (por definir y validar)

- Tiempo medio entre mensaje recibido y tarea estructurada generada
- % de tareas que requieren contexto adicional (needs_review)
- % de tareas asignadas automáticamente sin intervención manual
- Tiempo estimado ahorrado por equipo/mes
- Adopción por canal de comunicación (Discord, Teams, web)
