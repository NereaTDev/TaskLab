# Feedback de clientes

> Plantilla inicial. Espacio para centralizar feedback real de clientes y usuarios.

## Propósito de esta carpeta

Guardar feedback cualitativo recogido de clientes o usuarios (conversaciones, encuestas, comentarios en Discord/Teams, etc.) para informar decisiones de producto.

## Formato sugerido por entrada

- **Fecha**
- **Fuente** (entrevista, soporte, Discord, encuesta...)
- **Cliente/segmento**
- **Feedback textual o resumido**
- **Acción derivada** (si aplica)
