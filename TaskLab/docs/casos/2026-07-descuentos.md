# Caso: Sistema de descuentos

Resumen

Se desarrolló una funcionalidad para crear y editar descuentos en el nuevo panel de administración.

Problema

La tarea contenía únicamente una explicación funcional muy superficial.

No existían reglas de negocio claras.

La lógica tuvo que deducirse durante el desarrollo.

Fue necesario consultar varias veces a la CTO y posteriormente al desarrollador backend.

Después de implementar una primera versión aparecieron nuevas reuniones para redefinir el comportamiento.

La funcionalidad permaneció meses en estado "Done but Waiting".

Actualmente no existe certeza de que siga siendo válida.

Consecuencias

- Varias reuniones.
- Retrabajo.
- Tiempo perdido.
- Validación tardía.
- Incertidumbre.

Aprendizaje

La tarea nunca estuvo suficientemente preparada para comenzar el desarrollo.
