# Necesidad

## Definición

Una necesidad representa un problema, objetivo, cambio deseado o situación que requiere una actuación.

Es el objeto raíz del dominio de TaskLab.

Una necesidad no es todavía:

- una tarea;
- una solución;
- una implementación;
- una decisión;
- un ticket de una herramienta externa.

## Posibles orígenes

Una necesidad puede originarse en:

- un cliente;
- un empleado;
- un departamento;
- un sistema;
- una alerta;
- una regulación;
- la dirección;
- el mercado;
- una limitación técnica;
- una oportunidad detectada.

## Ejemplos

- Un cliente necesita filtrar un listado por provincia.
- Un sistema necesita recuperar un nivel aceptable de rendimiento.
- Una empresa necesita adaptarse a una nueva regulación.
- Un equipo necesita reducir la deuda técnica de un módulo.
- Marketing necesita mejorar la conversión de una campaña.

## Principio

TaskLab no debe confundir la expresión inicial de una necesidad con su solución.
