# Frases clave

Frases que resumen aprendizajes o giros de posicionamiento importantes durante el desarrollo del Second Brain. Se conservan literalmente, con el sprint en el que surgieron, para no perder el matiz original.

## Sprint 04

"La comprensión no se observa; se infiere a partir de la información disponible."

"Programar empieza cuando termina la incertidumbre suficiente para actuar."

"Una tarea no está preparada cuando tiene toda la información. Está preparada cuando ya no genera preguntas relevantes."

"TaskLab no responde preguntas; detecta las que todavía existen."

"La calidad de una tarea no depende de cuántos campos tenga. Depende de cuánta incertidumbre elimina."

## Sprint 05

"Todo cambio empieza encontrando dónde vive la funcionalidad."

"Antes de modificar un sistema, un desarrollador construye un modelo mental de cómo funciona."

"Las preguntas importantes no siempre hablan de código; muchas hablan de personas."

"El conocimiento no solo existe. También tiene propietarios."

"TaskLab no piensa como una IA. Piensa como un desarrollador antes de empezar a programar."

## Sprint 06

"TaskLab no recibe tickets. Recibe necesidades."

"Una necesidad no es una tarea ni una solución; es aquello que obliga a una organización a actuar."

"Toda ejecución es consecuencia de una cadena de decisiones."

"Quien ejecuta una decisión no siempre tiene autoridad para tomarla."

"El contexto es el conjunto de decisiones que explica por qué una actuación es como es."

"Cuando alguien consulta el historial, no siempre busca información: muchas veces busca el razonamiento perdido."

"TaskLab hace visibles las decisiones que hoy permanecen implícitas."

"El código es una consecuencia. La decisión explica por qué existe."

## Sprint 07

"Las herramientas actuales registran decisiones. TaskLab ayuda a descubrir las que todavía no existen."

"Una implementación correcta puede responder a una decisión equivocada."

"Los errores de decisión y los errores de implementación pertenecen a categorías distintas."

"El contexto perdido suele ser el razonamiento que llevó a una decisión."

"TaskLab actúa antes del trabajo, no durante él."
