# Frases clave

Frases que resumen aprendizajes o giros de posicionamiento importantes durante el desarrollo del Second Brain. Se conservan literalmente, con el sprint en el que surgieron, para no perder el matiz original.

## Sprint 04

"La comprensión no se observa; se infiere a partir de la información disponible."

"Programar empieza cuando termina la incertidumbre suficiente para actuar."

"Una tarea no está preparada cuando tiene toda la información. Está preparada cuando ya no genera preguntas relevantes."

"TaskLab no responde preguntas; detecta las que todavía existen."

"La calidad de una tarea no depende de cuántos campos tenga. Depende de cuánta incertidumbre elimina."
