# D-006 · Modelo mental del desarrollador

## Decisión

El producto se diseñará alrededor del razonamiento que sigue un desarrollador y no alrededor de la estructura de herramientas como Jira, Linear o Shortcut.

## Motivo

Las herramientas pueden cambiar.

El proceso mental permanece prácticamente constante.

## Estado

Activa.
