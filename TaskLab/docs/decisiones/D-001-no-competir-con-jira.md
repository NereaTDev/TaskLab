# D-001 · No competir con Jira

## Decisión

TaskLab no nace para sustituir Jira, Shortcut, Linear o herramientas similares.

Inicialmente su objetivo será complementar las herramientas existentes aportando **contexto, trazabilidad y conocimiento**.

## Motivo

Competir directamente contra gestores de tareas obligaría a reconstruir un mercado ya consolidado.

El valor diferencial de TaskLab estará en preservar conocimiento.

## Estado

Activa.
