# Decisiones

> Plantilla inicial. Registro histórico de decisiones estratégicas de TaskLab (ADR — Architecture/Business Decision Records).

## Propósito de esta carpeta

Dejar constancia de decisiones importantes (de negocio, producto o arquitectura) junto con el contexto y las razones que las motivaron, para no perder ese conocimiento con el tiempo.

## Formato de cada decisión

Cada archivo sigue el patrón `NNN-titulo-de-la-decision.md` y debe incluir:

- **Contexto**: qué situación llevó a tomar la decisión
- **Decisión**: qué se decidió exactamente
- **Consecuencias**: qué implica esta decisión a futuro
