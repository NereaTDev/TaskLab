# D-010 — Adaptar el repositorio Laravel existente

Decisión

El nuevo TaskLab se construirá progresivamente sobre el repositorio Laravel existente.

Motivo

El repositorio contiene trabajo previo, documentación, conocimiento acumulado y posiblemente componentes reutilizables.

Consecuencia

Antes de implementar nuevas funcionalidades debe auditarse la arquitectura actual y clasificarse qué se conserva, adapta, aísla o sustituye.

Estado

Activa.
