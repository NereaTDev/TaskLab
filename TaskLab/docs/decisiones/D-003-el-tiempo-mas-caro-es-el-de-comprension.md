# D-003 · El tiempo más caro es el de comprensión

## Decisión

TaskLab no buscará únicamente documentar tareas.

Buscará reducir el tiempo que un desarrollador necesita para comprender una funcionalidad antes de modificarla.

## Motivo

Las conversaciones realizadas muestran que el mayor tiempo perdido ocurre antes de escribir la primera línea de código.

Activa.
