# D-002 · El problema es la pérdida de contexto

## Decisión

TaskLab deja de definirse como un gestor de tareas.

A partir de ahora se define como un sistema para preservar el contexto y la trazabilidad de las decisiones que originan el desarrollo de software.

## Motivo

Los casos analizados muestran que el problema principal no es gestionar tareas.

El verdadero problema es la pérdida progresiva de conocimiento durante todo el ciclo de vida de una petición.

Activa.
