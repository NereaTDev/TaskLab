# D-011 — Comenzar con un Motor de Comprensión simulado

Decisión

El primer flujo vertical utilizará una implementación simulada del Motor de Comprensión antes de integrar un proveedor real de inteligencia artificial.

Motivo

Permite validar el contrato, la arquitectura, la interfaz y el recorrido completo sin introducir todavía costes, secretos, latencia o dependencia de un proveedor.

Consecuencia

La aplicación deberá depender de un contrato intercambiable y no directamente de una API específica.

Estado

Activa.
