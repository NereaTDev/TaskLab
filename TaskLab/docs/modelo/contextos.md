# Tipos de contexto

## Contexto estructural

Permite localizar la funcionalidad dentro del sistema.

Ejemplos

- módulo
- archivos
- arquitectura
- componentes
- variables
- servicios
- dependencias

Su objetivo es responder:

¿Dónde vive esta funcionalidad?

## Contexto funcional

Permite comprender el comportamiento del negocio.

Ejemplos

- funcionamiento actual
- comportamiento esperado
- reglas de negocio
- criterios de aceptación
- casos límite

Su objetivo es responder:

¿Qué debe cambiar exactamente?
