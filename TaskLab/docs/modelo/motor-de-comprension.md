# Motor de Comprensión

El Motor de Comprensión representa la secuencia de razonamiento que sigue un desarrollador antes de modificar un sistema.

No representa una implementación técnica.

Representa un modelo mental.

Versión 1

1. ¿Dónde está?
2. ¿Cómo funciona actualmente?
3. ¿Qué debe cambiar?
4. ¿Quién conoce realmente esta funcionalidad?
5. ¿Quién validará el resultado?
6. ¿Tengo suficiente información para decidir cómo modificarlo?
7. Comenzar la implementación.

Observación

TaskLab no intenta responder automáticamente todas las preguntas.

Su objetivo es detectar cuáles siguen abiertas.
