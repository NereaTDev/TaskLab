# Cadena de confianza

Durante el desarrollo siempre existen responsables asociados al conocimiento.

TaskLab debe ser capaz de identificar, cuando sea posible:

- Quién solicitó el cambio.
- Quién conoce funcionalmente esa parte del sistema.
- Quién posee el conocimiento técnico.
- Quién valida el resultado final.

Objetivo

Reducir el tiempo invertido buscando a la persona adecuada para resolver dudas.
