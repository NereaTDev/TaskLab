# Transformación de TaskLab

## Estado inicial

Existe una necesidad, pero todavía contiene incertidumbre, preguntas, supuestos o decisiones implícitas.

## Transformación

TaskLab ayuda a:

1. identificar la necesidad;
2. separar la necesidad de la solución propuesta;
3. detectar preguntas abiertas;
4. descubrir decisiones pendientes o implícitas;
5. identificar quién debe resolver cada decisión;
6. conservar el razonamiento y el contexto;
7. comprobar si existe suficiente claridad para actuar;
8. vincular la ejecución y la validación con las decisiones tomadas.

## Estado resultante

La organización dispone de una necesidad suficientemente comprendida y de una cadena explícita de decisiones que permite actuar con mayor confianza.

## Fórmula conceptual

Necesidad implícita

↓

Decisiones explícitas

↓

Actuación comprensible y validable
