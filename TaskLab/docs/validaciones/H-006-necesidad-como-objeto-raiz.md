# H-006 — La necesidad como objeto raíz

Hipótesis

Modelar una necesidad como objeto raíz permitirá representar trabajo procedente de distintas herramientas, departamentos y fuentes sin depender del concepto de ticket.

Estado

Pendiente de validar.

Nivel de confianza

Media.

Cómo podría demostrarse falsa

- Si la mayoría de entradas reales no pueden expresarse como una necesidad.
- Si el concepto resulta demasiado abstracto para los usuarios.
- Si obliga a introducir pasos innecesarios antes de analizar una petición.
- Si no mejora el modelo respecto a una solicitud de cambio o unidad de trabajo.
