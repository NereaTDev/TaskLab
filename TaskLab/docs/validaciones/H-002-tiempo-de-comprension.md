# H-002 · Tiempo de comprensión

Hipótesis

El mayor coste de una tarea no es implementarla.

El mayor coste es comprender correctamente qué ocurre actualmente y qué debe ocurrir después del cambio.

Si TaskLab reduce ese tiempo de comprensión, aumentará significativamente la productividad del desarrollador.

Estado

Pendiente de validar.
