# H-007 — Decisiones implícitas

Hipótesis

Una parte significativa de la incertidumbre organizativa aparece porque las decisiones necesarias para ejecutar una necesidad permanecen implícitas, distribuidas o sin propietario claro.

Estado

Pendiente de validar.

Nivel de confianza

Media.

Cómo podría demostrarse falsa

- Si los equipos ya registran de forma suficiente todas las decisiones relevantes.
- Si hacer explícitas las decisiones no reduce preguntas ni retrabajo.
- Si el coste de registrarlas es mayor que el valor generado.
- Si los usuarios no consideran necesario conservarlas una vez ejecutado el trabajo.
